# Fractals of Entropy

### Android Top-Down Survival Shooter · Unity · C#

**Fractals of Entropy** is an Android top-down survival shooter created and developed by **Maximilian Vincentius**. The project was produced through a complete game-development workflow: planning, 3D asset creation, Unity implementation, mobile interface development, testing, optimization, and portfolio presentation.

> This repository is a visual portfolio containing project documentation and showcase images. The Unity source project and editable production files are not distributed here.

## Project Information

| Item | Details |
| --- | --- |
| Creator and Developer | **Maximilian Vincentius** |
| Development Period | December 2023 – August 2026 |
| Platform | Android, landscape orientation |
| Genre | Top-Down Survival Shooter |
| Engine | Unity 6000.1.11f1 |
| Programming Language | C# |
| 3D Production | Autodesk Maya |
| Texturing | Adobe Substance 3D Painter and Adobe Photoshop |

## Gameplay Features

- Twin-stick touchscreen movement and independent aiming.
- Projectile combat with health, damage, knockback, shooting, and reloading.
- Enemy AI, enemy elimination, collectible coins, missions, and claimable rewards.
- Pistol, Revolver, Rifle, Shotgun, and Sniper Rifle weapon categories.
- Three weapon slots with weapon switching, pickup, drop, and ammunition management.
- Health, Speed, Immunity, and Damage Boost items or temporary buffs.
- Weapon and ammunition shops with item prices and statistics.
- Multiple player profiles with save, load, and delete functionality.
- Persistent player and world data, including position, health, coins, weapons, ammunition, missions, enemies, and collected items.

## Production Workflow

### 1. Planning and Visual Direction

The project began with a stylized mobile-game direction focused on readable environments, clear combat feedback, and landscape touchscreen controls. Gameplay systems, asset requirements, animation sets, and interface elements were planned around the intended survival-shooter experience.

### 2. 3D Modeling and UV Mapping

Characters, the robot enemy, weapons, buildings, vegetation, terrain pieces, and environmental props were modeled in **Autodesk Maya**. Their UV layouts were prepared to organize texture space, maintain consistent detail, and support efficient texture production.

### 3. Texturing

Textures and material details were produced in **Adobe Substance 3D Painter** and refined in **Adobe Photoshop**. The finished texture maps were exported and configured as Unity materials.

### 4. Rigging and Animation

The player character and robot enemy were rigged and animated in **Maya**. Their animation sets were exported, integrated, and tested for gameplay use in Unity.

### 5. Unity Integration and C# Development

Models, textures, materials, rigs, and animations were assembled in **Unity**. The gameplay code was developed in **C#**, covering player controls, combat, weapons, enemy behavior, pickups, missions, rewards, buffs, shops, UI logic, and profile persistence.

### 6. Mobile Interface and Testing

The Android landscape interface connects virtual joysticks, interaction buttons, weapon slots, health and ammunition information, missions, shops, and profile management to the gameplay systems. The complete loop was tested and adjusted for controls, collisions, lighting, rendering, interaction behavior, and persistent data.

### 7. Documentation and Presentation

Final screenshots, asset presentations, animation showcases, and gameplay footage were prepared to document the project's creative and technical results.
